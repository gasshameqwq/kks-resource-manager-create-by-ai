## 2. 逐项说明

### 2.1 KKTools —— MIT

- 用途：KKS/KK 卡片（PNG 尾部 MessagePack 数据块）解析、PyQt6 UI 的
  `QThread` 后台任务模式（`ui/worker.py`）。
- 处理方式：复制到本项目时，在该文件头部保留原始版权与 MIT 声明，并在本文件登记。
- 注意：沿用其**解析逻辑与字段语义**，但目录结构、数据库 schema、分类模型为本项目自有设计，
  不要为了「贴合参考项目」而改动本项目已定型的 schema。

### 2.2 koikatu.js —— MIT（声明存在于 `package.json` / README）

- 用途：卡片格式与字段语义的交叉验证，避免单一实现带来的理解偏差。
- 风险：仓库内**没有独立的 LICENSE 文件**，只有元数据声明。
  因此默认只做参考；若将来需要直接复制代码片段，先确认上游许可状态并在此处记录结论。

### 2.3 KKCardModCheck —— 无 License

- 用途：仅参考其**「卡片依赖 MOD、缺失 MOD 提示」的产品设计**。
- 约束：**不得复制任何代码**。本项目 `resource_mods` 以 `mod_guid` 作为主键，
  从而支持「未安装的 MOD 依赖也能记录」，这一设计是独立实现的，与本项目 schema 一致。

## 3. 参考源码的存放规则

参考仓库**不纳入版本管理**，本地克隆到下列任一目录即可（已在 `.gitignore` 中忽略）：

```

```

禁止把参考仓库的内容直接提交进 `core/`、`ui/`、`tools/`。
